# **FEASolver_1.0**

## **一：FEASolver_1.0功能点描述**

#### 1：基于自定义输入文件格式，完成各向同性材料的1D,2D,3D的问题的线弹性静力学求解。暂时不考虑等参单元的设计。
#### 2：自定义输出文件。在输出文件中记录结构位移场，应力场和应变场。要求和商软计算误差小于1%
#### 3：具备小型线性方程组求解能力( 矩阵阶数<=100 )

## **二：代码架构**
### 结构示意：
    输入 ---> 模型映射器 ---> 模型关联器 ---> 矩阵组装器 ---> 数值求解器 ---> 后处理单元 ---> 输出
### 输入:
  input文件。
###  有限元模型映射器:
 通过映射关系初步生成有限元模型。该模型仅存储了输入文件信息，并不进行任何计算。
### 模型关联器
 将模型各个部分进行关联，生成一个完备的有限元模型。主要目的是生成各个单元的单元刚度矩阵、载荷矩阵等。
### 矩阵组装器
 负责根据模型库中的信息，在全局坐标系下生成总体刚度矩阵和总体载荷列阵
### 数值求解器
 求解线性方程组。
### 后处理单元
 处理数据得到目标变量。
### 输出:
         output文件。
## **三：项目细分**
### **1.模型映射器（已初步完成）**
#### （1）文件解析器：
解析文件信息  
注：文件解析器需要将文件解析为统一格式(一个卡片10个数据，卡片个数不定。具体参考bdf手册)  
完成统一格式的转换后才能方便的调用元件接口；
#### （2）对象注册器：获取关键字到元件对象的映射关系
映射表方案一：关键字 <-> 元件工厂(工厂方法模式)  
要求：在编译时期就创建好映射表
#### （3）元件映射器：基于映射关系将文件信息生成元件对象
### **2.模型关联器（已初步完成）**
以单元、载荷等为起点，索引各id，获取生成单元刚度矩阵所需要的量
### **3.矩阵组装器(已初步完成)**
### 输入:
      有限元模型库
### 输出:
      总体刚度矩阵、总体载荷列阵 
### 可能的问题
##### （1）单元刚度矩阵（单元载荷列阵）定义在局部坐标系下，需要通过坐标变换得到全局坐标系下的单元刚度矩阵（总体载荷列阵）
      矩阵从局部坐标变换到全局坐标系需要考虑具体的单元情况，所以需要在具体单元内进行，载荷同理。
##### （2）将多个单元刚度矩阵如何组装成总体刚度矩阵
##### （3）组装生成总体坐标系下的载荷列阵
